# Benson M. Merita · Data Analyst Portfolio

👉 **Live site:** https://benson-merita.netlify.app *(update this link after deploying)*

Eight end-to-end data projects built in Python and SQL, using Kenyan business examples.

## Featured projects

| # | Project | Skills shown | Data |
|---|---|---|---|
| 01 | Digital lending credit risk in SQL | SQL CTEs and window functions, vintages, PAR30/90, expected loss, pricing approval rules | Synthetic |
| 02 | Predicting loan default | Leakage checks, logistic regression vs boosting, AUC/KS, profit-based cut-off, fairness | Synthetic |
| 03 | M-Pesa personal finance analytics | Text parsing, categorisation, RFM, anomaly detection, back-tested forecast | Synthetic |
| 04 | Customer segmentation for a SACCO | Feature scaling, k-means, silhouette and stability checks, segment actions | Synthetic |
| 05 | Insurance data quality and claim frequency | Rules-based validation, quarantine, rates with confidence intervals | Synthetic |
| 06 | Shop sales and ledger reconciliation | Data cleaning, validated merges, KPIs, Pareto, reconciliation to finance | Synthetic |

## What's in this repo

- `index.html`: the portfolio website
- `notebooks/`: one Jupyter notebook per project, showing every step from raw data to recommendations ([start here](notebooks/README.md))
- `excel/`: Project 06 rebuilt with live Excel formulas
- `datasets/`: every dataset used, with a README explaining each file
- `datasets/01-lending-credit-risk/sql/`: the SQL queries and the SQLite database they run on
- `datasets/01-lending-credit-risk/powerbi/`: star-schema tables and DAX measures for the loan book dashboard

To run the notebooks: `pip install -r requirements.txt`, then open them from the `notebooks/` folder.

Longer walkthroughs: [Data Science from Zero to Advanced](https://merita-analytics-data-science.netlify.app/part-19)
